# Laboratório 02 — Estratégias e Níveis de Teste na Prática
> **Domínio Escolhido:** Sistema Julgador de Programação Competitiva (Online Judge)

Este repositório contém a documentação técnica das 13 abordagens de teste de software aplicadas ao cenário de um julgador automático de submissões de código, divididas em 4 níveis clássicos de teste.

---

## 📁 Estrutura da Documentação

Para facilitar a navegação e manter o relatório organizado, o conteúdo foi dividido por níveis na pasta [`docs/`](./docs/):

* **[01. Teste de Unidade (Unit Testing)](./docs/01-unidade.md)**
  * 1.1 Verificação de lógica atômica na classe `VerdictEvaluator`
* **[02. Teste de Integração (Integration Testing)](./docs/02-integracao.md)**
  * 2.1 Integração Não Incremental (Big Bang)
  * 2.2 Integração Incremental Top-Down com Stubs
  * 2.3 Integração Incremental Bottom-Up com Drivers
  * 2.4 Teste de Fumaça (Smoke Testing)
  * 2.5 Teste de Regressão
* **[03. Teste de Validação (Validation Testing)](./docs/03-validacao.md)**
  * 3.1 Critérios de Aceitação (User Acceptance Testing)
  * 3.2 Teste Alfa (Alpha Testing)
  * 3.3 Teste Beta (Beta Testing)
* **[04. Teste de Sistema (System Testing)](./docs/04-sistema.md)**
  * 4.1 Teste de Recuperação (Recovery Testing)
  * 4.2 Teste de Segurança (Security Testing)
  * 4.3 Teste de Estresse (Stress Testing)
  * 4.4 Teste de Desempenho (Performance Testing)
